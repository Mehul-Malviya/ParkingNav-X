# Map calibration report

Generated by `scripts/calibrate_campus_from_osm.py` (spec: `configs/campus/vitap_calibration.yaml`).
Data (c) OpenStreetMap contributors, ODbL 1.0.

## Method

* **Exact** positions: centroid of the OSM way. Never overwritten by an estimate.
* **Approximate** positions: pixel positions read from the reference image, converted with an affine transform fitted to 10 exact OSM control buildings (fit max 0.9 m, leave-one-out mean 0.5 m / max 1.6 m, scale ~2.07 px/m). The control fit is accurate, but the pixel readings and the image author's own placement of lots/gates are not verifiable, so these points are treated as **+/-25 m**. They are not surveyed.
* **Roads**: shortest path along real OSM roads (vehicle roads for drivable links; vehicle roads and footways for walk links) between the two end nodes. The first/last point is the node itself, so a short off-road stub joins nodes that are not on a mapped road.
* **Unchanged on purpose**: `length_meters`, `expected_travel_time_seconds` and edge weights of every pre-existing road. Routing costs are **not** geographically recalibrated. Only roads added later (LH-3) have weights derived from their geometry, because no earlier value exists.

## Removed destinations

Removed from the config, routing graph, database, API and UI. The seeded simulation draws vehicle destinations from the destinations table, so removing one **shifts every seeded result** relative to the committed experiments (their files are untouched, but re-running them gives different numbers).

* **AP-2** (`vitap-osm-ap2-001`): AP-2: removed on request (no reference coordinates; not in OSM). Roads removed with it: vitap-road-academic-lot-to-ap2, vitap-road-sports-lot-to-ap2.

## Parking boundaries

* Overflow Parking: real OSM footprints (two ways either side of the main avenue).
* All other lots: `boundary_source: placeholder` (100 m box around the approximate centre). **Not a real boundary**; the UI does not draw it as one.

## Path coverage

How far each node is from a mapped OSM road. Where OSM has no path between a node and the road network, a dotted *access link* is drawn (`access_start_m` / `access_end_m` per road, which also include the stretch inside a building); no path is invented. For buildings the path now ends at the building outline (entrance side), not the centroid.
